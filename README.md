## 5 Такой же счетчик, как и в первом задании, только это генератор и использует yield

![Меню](https://github.com/daretodream666/Software_Engineering/blob/Tema_11/pics/lab5.png)

### Выводы

Функция countdown является генератором, который возвращает значения от заданного числа до 0. Ключевое слово yield приостанавливает выполнение функции и сохраняет её состояние, позволяя генератору выдавать значения по одному при каждой итерации. Генераторы экономят память, так как не хранят все значения сразу, а генерируют их на лету. Объект генератора можно итерировать в цикле for, который неявно вызывает next() для получения каждого следующего значения до завершения последовательности.


## 1 Вас никак не могут оставить числа Фибоначчи, очень уж они вас заинтересовали. Изучив новые возможности Python вы решили реализовать программу, которая считает числа Фибоначчи при помощи итераторов. Расчет начинается с чисел 1 и 1. Создайте функцию fib(n), генерирующую n чисел Фибоначчи с минимальными затратами ресурсов. Для реализации этой функции потребуется обратиться к инструкции yield (Она не сохраняет в оперативной памяти огромную последовательность, а дает возможность “доставать” промежуточные результаты по одному). Результатом решения задачи будет листинг кода и вывод в консоль с числом Фибоначчи от 200.

![Меню](https://github.com/daretodream666/Software_Engineering/blob/Tema_11/pics/sam1.png)

### Выводы

Генератор fib эффективно генерирует числа Фибоначчи без хранения всей последовательности в памяти. Функция enumerate с start=1 удобна для нумерации элементов. Оператор break останавливает цикл после нахождения 200-го числа, что экономит вычислительные ресурсы.
